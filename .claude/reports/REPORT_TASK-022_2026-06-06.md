## Что сделано

- На VPS добавлен rate-limit для форм `/api/*` средствами nginx (без Arcjet/внешних вендоров).
- Зона лимита по IP клиента (`$binary_remote_addr`), 10 запросов/мин, всплеск 5 без задержки,
  статус отказа 429.
- `GET /api/healthz` исключён из лимита (отдельный `location = /api/healthz`) — мониторинг не страдает.
- Лимит только на `/api/` (страницы `/` не трогались). ufw/sshd/PM2/код API не менялись.

## Фрагмент конфига

`/etc/nginx/conf.d/ratelimit.conf`:
```nginx
limit_req_zone $binary_remote_addr zone=api_forms:10m rate=10r/m;
```

`/etc/nginx/sites-available/gpeters.ru` (в server-блоке 443):
```nginx
    location = /api/healthz {
        proxy_pass http://127.0.0.1:3001;
        proxy_http_version 1.1;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }

    location /api/ {
        limit_req zone=api_forms burst=5 nodelay;
        limit_req_status 429;
        proxy_pass http://127.0.0.1:3001;
        proxy_http_version 1.1;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }
```

## Проблемы / открытые вопросы

- Ключ лимита — `$binary_remote_addr` (реальный IP внешнего клиента; через Vercel формы не ходят,
  X-Forwarded-For в ключе не используется — по промту). Щадящий лимит: человек не упрётся,
  перебор/боты режутся.
- Конфиги nginx в репозитории не хранятся — фрагменты приложены к отчёту (как в REPORT_TASK-015).
