## План бэкапов (куда / сколько / как восстановить)

- **Куда:** `/var/backups/postgres/antiage-YYYY-MM-DD.sql.gz` — на том же РФ-сервере (152-ФЗ, ПДн в РФ).
- **Когда/как часто:** ежедневно 03:30 MSK (systemd `pg-backup.timer`); один файл в сутки.
- **Хранение:** ~14 дней (старше — удаляются ротацией). При наполнении БД размер дампа вырастет;
  места с запасом.
- **Восстановление** (во ВРЕМЕННУЮ или новую БД — безопасно):
  ```bash
  sudo -u postgres createdb <target_db>
  gunzip -c /var/backups/postgres/antiage-<date>.sql.gz | sudo -u postgres psql <target_db>
  sudo -u postgres psql -c '\dt' <target_db>   # проверка
  ```
  Восстановление поверх боевой `antiage` — отдельная осторожная процедура (с остановкой записи/
  пересозданием БД); в этой задаче проверялось только на временной копии.
- **Запуск вручную:** `sudo systemctl start pg-backup.service` · логи: `journalctl -u pg-backup.service`.
