# REPORT TASK-076: Видео не блокируется на «3g»/VPN — 2026-06-09

**Агент:** VS Code Claude
**Статус:** Done

## Что изменено (одно условие)

В `Hero.tsx` (логика lazy-видео из TASK-073) из списка «медленных» типов сети убран `3g`:

```diff
- ["slow-2g", "2g", "3g"].includes(conn.effectiveType ?? "")
+ ["slow-2g", "2g"].includes(conn.effectiveType ?? "")
```

**Зачем:** Chrome (особенно через VPN и при задержке) часто пессимистично рапортует
`effectiveType="3g"` на нормальных каналах → `slowNet=true` → `showVideo=false` → `<video>`
вообще не монтировался (виден только постер), и выбор источника Vercel→Москва (TASK-075) не
запускался. Теперь постер-only остаётся ТОЛЬКО при `saveData=true` или `slow-2g/2g`; `3g` и выше
монтируют видео. Прочую логику (постер, мобильный брейкпоинт, reduced-motion, таймаут-фолбэк)
не трогал.
