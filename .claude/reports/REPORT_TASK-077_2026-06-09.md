## Что изменено

Фикс регрессии из TASK-075: Vercel в РФ заблокирован, а источник СТАРТОВАЛ с Vercel →
каждый РФ-посетитель (основная аудитория) ждал таймаут 2.5с/«висел» до фолбэка на Москву.
Теперь НАЧАЛЬНЫЙ источник выбирается по часовому поясу браузера.

- Добавлен helper `isRuLikeTimeZone()`: читает `Intl.DateTimeFormat().resolvedOptions().timeZone`
  и сверяет с `Set` РФ/СНГ таймзон (Europe/Moscow…Asia/Anadyr + СНГ: Almaty/Tashkent/Minsk/
  Tbilisi/Yerevan/Baku). Точное сравнение по множеству, без эвристик по `navigator.language`.
  Если таймзону не определить (пусто/исключение) → `true` (безопасный дефолт Москва).
- В `evaluate()` стартовый src: `isRuLikeTimeZone() ? VIDEO_ORIGIN_URL : VIDEO_CDN_URL`.
  - РФ/СНГ → сразу Москва (`/media`), к Vercel НЕ обращаемся, таймаута нет.
  - Зарубеж → Vercel-first, при таймауте/ошибке фолбэк на Москву (TASK-075) — без изменений.
- Гард `switchedRef`, таймаут-эффект, фолбэк, постер, lazy, reduced-motion, saveData и
  3g-фикс (TASK-076) — НЕ тронуты. Для РФ-ветки мы и так на Москве (таймаут-эффект для неё
  не запускается, т.к. `videoSrc !== VIDEO_CDN_URL`).
