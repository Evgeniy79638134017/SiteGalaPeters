# PROMPT_075_video_source_race

## Контекст
TASK-075 (SPRINT-4): ускорить hero-видео для ЗАРУБЕЖНЫХ пользователей, не меняя ролик и
не ломая РФ. Сейчас видео отдаётся только с московского сервера (`/media/hero-bg.mp4`) —
для России быстро, для заграницы медленно (всё идёт через Москву, ~11 c на 9,5 МБ).
Решение из VIDEO_MULTISOURCE_RESEARCH.md: дать ВТОРОЙ источник — Vercel (глобальный edge),
и на клиенте «сначала Vercel, если не заиграл за ~2,5 c → Москва». Из РФ Vercel заблокирован
→ таймаут → Москва (как сейчас). Cross-origin воспроизведение `<video>` CORS не требует.
Прочитай: CLAUDE.md, VIDEO_MULTISOURCE_RESEARCH.md, src/components/sections/Hero.tsx
(логика showVideo/poster/reduced-motion из TASK-073), .claude/reports/REPORT_TASK-015 (Vercel-домен проекта).

## Цель
Hero-видео грузится быстро и в РФ (Москва), и за рубежом (Vercel), с надёжным фолбэком.
Готово =
(1) тот же файл лежит в `antiage-platform/public/media/hero-bg.mp4` (копия из
    ContentFiles/web_ready/hero-bg.mp4) и после деплоя отдаётся Vercel:
    `https://<vercel-домен>/media/hero-bg.mp4` → 200 (проверить реальный prod-домен,
    ожидаемо gala-antiage.vercel.app);
(2) в Hero реализован выбор источника: по умолчанию пробуется Vercel-URL; если в течение
    ~2500 мс не наступило `canplay`/`loadeddata` ИЛИ событие `error` → переключение на
    московский `/media/hero-bg.mp4` (относительный, same-origin) с `load()`+`play()`;
(3) постер, lazy (desktop+быстрая сеть), `prefers-reduced-motion`/saveData — без изменений;
(4) cross-origin воспроизведение без атрибута `crossorigin` (пиксели не читаем);
(5) проверка: из не-РФ точки используется Vercel (быстрее); имитация недоступности Vercel
    → фолбэк на Москву срабатывает; в обоих случаях видео играет, в консоли нет ошибок;
(6) lint/tsc/build зелёные; прод-деплой Ready.

## Вайб
Точечно: меняем только источник у hero-`<video>` + маленький клиентский хук выбора.
Композицию, тексты, формы не трогать. Фолбэк на Москву обязателен (РФ не должна пострадать).

## Технические параметры
- cwd antiage-platform/. Vercel-URL вынести в константу (напр. в lib/constants
  `VIDEO_CDN_URL`), реальный prod-домен подтвердить curl'ом ДО прописывания.
- Файл в public/media — это деплой-ассет; .gitignore его НЕ игнорирует (см. TASK-041:
  игнорируется только ContentFiles/, public/ в git). Закоммитить видео в public/media.
- Логика: показывать <video> только когда showVideo=true (как в TASK-073). Внутри —
  state выбранного src; начать с Vercel, таймер 2500мс, слушатели canplay/loadeddata/error;
  очистить таймер при успехе; гард от повторных переключений; при фолбэке — Москва.
- preload="metadata", muted, loop, playsInline, autoplay; poster прежний.
- Edge: если Vercel сразу error (RF/блок) — не ждать весь таймаут, сразу Москва.
  Если оба недоступны — остаётся постер (как сейчас), без «крутилки».
- Замер для отчёта: `curl -w` времени по обоим URL (Vercel и Москва) из доступной точки.
