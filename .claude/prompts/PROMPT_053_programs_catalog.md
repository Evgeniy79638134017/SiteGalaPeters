# PROMPT_053_programs_catalog

## Контекст
TASK-053 (SPRINT-3, ключевая контент-задача): каталог из 8 программ по структуре и
наполнению doksveta.ru/programs с адаптацией под Tone of Voice Галины.
ОБЯЗАТЕЛЬНО прочитай ПЕРЕД стартом: PROGRAMS_TOV_DRAFT.md (корень репо — правила
адаптации, утверждены владельцем), CLAUDE.md, src/content/programs.ts (текущие 3 «кита»),
src/app/programs/**, src/components/shared/Disclaimer.tsx, src/app/sitemap.ts,
src/lib/constants.ts (ORDER_URL из TASK-054).

## Цель
На gpeters.ru — каталог 8 программ + 8 подстраниц, тон Галины, кнопки заказа работают.
Готово =
(1) /programs: грид 8 карточек программ (название, «для кого», «от 4 месяцев»,
    Подробнее) + секция «Подход: три кита» со ссылками на существующие
    /programs/{biochemistry,biomechanics,bioenergy} (эти 3 страницы НЕ удалять);
(2) 8 подстраниц /programs/<slug> со slug'ами как у доксветы
    (serdechno-sosudistaya-sistema, son-energiya, nervnaya-sistema,
    gormonalnyj-balans, sustavy-i-kosti, gribki-i-parazity,
    pischevaritelnaya-sistema, immunnaya-sistema), структура страницы как у
    доксветы: hero → «подойдёт, если» → причины → краткая программа (этапы по
    месяцам + комплексы с дозировками) → подробная программа → ожидаемые
    результаты → FAQ → CTA;
(3) контент перенесён из исходников docsveta БЕЗ изменений составов/дозировок/этапов;
    подача адаптирована по таблице правил PROGRAMS_TOV_DRAFT §2 (Галина, 30+ лет,
    «продукт своего продукта», дружеский тон; «восстановление/выздоровление» →
    «поддержка организма»; убраны врачебные регалии и «снижение зависимости от
    лекарств»); цифры блока опыта: «30+ лет», «1000+ благодарных людей»;
(4) кнопки «Заказать комплексы» и «Написать в Telegram» → ORDER_URL и
    TELEGRAM_CHANNEL_URL из constants (реф-код подставится позже одной правкой);
(5) на каждой подстранице — компонент Disclaimer (БАД) + мед.дисклеймер в футере
    уже есть; блок «О производителе» (AgenYZ/Честный знак) перенести;
(6) все 8 новых slug в sitemap; lint/tsc/build зелёные; прод: каталог и минимум
    2 подстраницы проверены вживую.

## Вайб
Перенос, не сочинительство: факты/составы 1:1, меняется только голос. Большая задача —
делай инкрементально (данные → каталог → подстраницы), коммить можно одним PR-коммитом.
