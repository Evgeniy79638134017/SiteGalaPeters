# PROMPT_057_download_table

## Контекст
TASK-057 (SPRINT-3): кнопка «Скачать таблицу приёма» на странице программы —
скачивает JPG расписания (как на doksveta; пример-референс владельца — зелёная
таблица ПЕРИОД/УТРО/ЗАВТРАК/ОБЕД/УЖИН). У нас данные расписания уже есть в
src/content/health-programs.ts. Прочитай: CLAUDE.md,
src/content/health-programs.ts (структура schedule), src/components/programs/
HealthProgramPage.tsx (где рендерится таблица «Расписание приёма»).

## Цель
Кнопка отдаёт JPG-картинку расписания текущей программы.
Готово = (1) на странице программы кнопка «Скачать таблицу приёма»; (2) клик →
скачивается <slug>-raspisanie.jpg с отрисованной таблицей расписания (заголовок
программы + строки период/приёмы) в палитре сайта (teal-шапка, не зелёная доксветы);
(3) работает в Chrome (проверить), файл открывается; (4) lint/tsc/build зелёные;
прод — проверено на 1 программе (файл скачался и валиден).

## Вайб
Клиентский рендер DOM→картинка. Минимум зависимостей. Без серверной генерации.

## Технические параметры
- Библиотека: html2canvas (или html-to-image — на выбор), точная версия в package.json
  (без ^), зафиксировать дельту размера бандла в CHANGELOG.
- Подход: отдельный скрытый off-screen контейнер с печатной версткой таблицы
  (полная, не адаптивно-схлопнутая) → html2canvas → canvas.toDataURL("image/jpeg",0.92)
  → программный <a download>. Кнопка — client component.
- Палитра: шапка таблицы — teal (бренд), чередование строк светлым; шрифт читаемый;
  ширина ~1000-1200px для качества.
- БАД-дисклеймер строкой внизу картинки: «БАД. Не является лекарственным средством.»
- Edge: убедиться, что веб-шрифты/эмодзи не ломают рендер (при необходимости — без эмодзи
  в картинке); картинка не должна быть пустой/обрезанной.

## Visual Guidance
- Структура колонок — как в референсе доксветы (ПЕРИОД | УТРО | ЗАВТРАК | ОБЕД | УЖИН),
  но если данные health-programs.ts по месяцам/этапам — отрисуй по имеющейся структуре
  (период → списки приёмов). Цвета — палитра сайта.
