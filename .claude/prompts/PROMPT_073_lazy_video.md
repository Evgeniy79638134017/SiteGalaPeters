# PROMPT_073_lazy_video

## Контекст
TASK-073 (SPRINT-4, Вариант A): снять тяжёлое hero-видео с критического пути для
медленных соединений и мобильных — показывать постер, видео подгружать аккуратно.
Прочитай: CLAUDE.md, src/components/sections/Hero.tsx (видео-слой из TASK-051),
PERF_ARCHITECTURE_PLAN.md (§3.4).

## Цель
Постер мгновенно, видео не мешает первому экрану и не грузится зря на мобильных/медленных.
Готово = (1) на мобильных (узкий вьюпорт) и при `navigator.connection.saveData`/медленном
типе сети — рендерится статичный постер без загрузки video; (2) на десктопе видео грузится
после первого рендера (`preload="metadata"`, старт по готовности, не блокирует LCP);
(3) prefers-reduced-motion — как было: только постер; (4) hero визуально не «прыгает»
(постер и видео одного кадра — уже так); (5) lint/tsc/build зелёные; прод проверен
desktop + mobile.

## Вайб
Прогрессивное улучшение: база — постер-картинка; видео — поверх, когда уместно. Тексты/CTA
и композицию hero не менять.

  нет — считать ок для десктопа, постер для узких экранов).
